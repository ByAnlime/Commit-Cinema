# 🎬 Commit-Cinema (Web Oficial)

Bienvenido al repositorio de **Commit-Cinema**, el cine favorito de la facultad.

Este proyecto web contiene la página principal del cine, incluyendo:
- **Cartelera actual**: Películas en emisión, sinopsis y sesiones.
- **Estilos temáticos**: Colores y ambientación de temporada en `css/styles.css`.
- **Promociones**: Menú de snacks y ofertas de temporada.

## 🛠️ Cómo empezar la práctica (Flujo con Fork)

1. **Hacer un Fork**: Haz clic en el botón `Fork` en la parte superior derecha de GitHub/GitLab para crear una copia en la cuenta de tu grupo.
2. **Clonar tu propio Fork en local**:
   ```bash
   git clone https://github.com/<TU_USUARIO_O_GRUPO>/Commit-Cinema.git
   cd Commit-Cinema
   ```
3. **Vincular el repositorio original como remoto `upstream`**:
   ```bash
   git remote add upstream https://github.com/anlime10/Commit-Cinema.git
   git remote -v
   ```
